Taproot output helper — bc1p-shaped stub.

## Features

- BTC path m/86'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd taproot-output
cargo build --release
./target/release/taproot-output --help
```

## Tests

```bash
cargo test
```
